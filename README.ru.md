# Termulin ❯

**Termulin** — это эстетичная, быстрая и минималистичная тема для Windows Terminal и PowerShell 7. Вдохновленная эстетикой Linux-окружений и r/unixporn, она превращает стандартную консоль Windows в современный, стильный инструмент для работы.

Проект создан с уважением к сообществу и любовью к коду.

## ✨ Особенности

- 🚀 **Мгновенный запуск**: Системная информация (CPU, RAM, ОС) кешируется, поэтому терминал открывается за доли секунды.
- 🎨 **4 предустановленные темы**:
  - `TRL Snow` — Графитовые тона (идеально подходит для фонов с горами).
  - `TRL Angel` — Мраморный монохром (для минималистичных черно-белых фонов).
  - `TRL Sakura` — Пепельно-розовый (нежные пастельные тона).
  - `Custom` — Создайте свою тему с нуля!
- 🌌 **Эстетичный фон**: Использует локальные изображения с эффектом акрилового стекла (полупрозрачность).
- 💻 **Умный промт**: Двухстрочное приглашение с часами, именем текущей папки и версией PowerShell.
- 🎬 **Boot-анимация**: Отдельный ярлык запускает терминал с имитацией загрузки ядра Linux (строки логов, 3D ASCII-арт).
- 🛠️ **Универсальная установка**: Скрипт `Setup.bat` сам найдет PowerShell 7 (даже из Microsoft Store), установит его при необходимости и всё настроит.

---

## ⚙️ Требования

- **Windows 10 или Windows 11**.
- **Windows Terminal** (рекомендуется версия из Microsoft Store).
- **PowerShell 7** (установщик `Setup.bat` скачает и установит его автоматически через `winget`, если его нет).
- **Шрифт Liberation Mono** (желательно установить для идеального отображения, но если его нет — терминал использует стандартный Cascadia Mono).

## 🚀 Установка (Пошагово для чайников)

1. **Скачайте проект**
   - Нажмите на зеленую кнопку `Code` вверху страницы и выберите `Download ZIP`.
   - Распакуйте архив в любую удобную папку (например, `C:\Tools\Termulin`).

2. **Запустите установщик**
   - Откройте папку с проектом и дважды кликните по файлу **`Setup.bat`**.
   - Если Windows выдаст синее окно «Система Windows защитила ваш компьютер», нажмите **«Подробнее»** -> **«Выполнить в любом случае»** (это нормально для `.bat` файлов из интернета).

3. **Следуйте инструкциям в консоли**
   - Скрипт проверит наличие PowerShell 7. Если его нет, он начнет установку через `winget`.
   - Вам будет предложено меню выбора темы (введите цифру от 1 до 4 и нажмите `Enter`).
   - Если выберете `4` (Кастомная тема), скрипт пошагово спросит путь к картинке, цвета (в формате HEX) и шаблон промта.

4. **Готово!**
   - На рабочем столе появятся ярлыки для запуска.
   - Откройте новый терминал (или используйте ярлык) и наслаждайтесь.

## 🗑️ Как удалить

Если вы захотите полностью удалить тему и вернуть настройки терминала по умолчанию:
1. Откройте командную строку (`cmd`) или PowerShell.
2. Перейдите в папку с проектом: `cd C:\Tools\Termulin`.
3. Выполните команду:
   ```cmd
   Setup.bat -Uninstall
   ```
4. Скрипт удалит все созданные профили, схемы цветов и ярлыки. Перезапустите Windows Terminal, чтобы изменения вступили в силу.

## 📂 Что делает каждый файл? (Для продвинутых)

| Файл | Назначение | Что можно изменить |
| :--- | :--- | :--- |
| **`Setup.bat`** | Универсальный лаунчер. Ищет PowerShell 7 (в том числе Store-версию), при необходимости устанавливает его и запускает `Install.ps1` или `Uninstall.ps1`. | Имя ярлыка в `title`, логику поиска `pwsh`. |
| **`Install.ps1`** | Главный установщик. Создает профили в Windows Terminal, настраивает цвета, создает ярлыки на рабочем столе и прописывает модуль в ваш профиль PowerShell. | Схемы цветов (HEX-коды), прозрачность фона (`opacity`), пути к картинкам в папке `background/`. |
| **`Uninstall.ps1`** | Полностью удаляет все следы Termulin из Windows Terminal и профиля PowerShell. | Список ярлыков для удаления. |
| **`Boot.ps1`** | Скрипт анимации загрузки. Выводит логи, 3D-арт и запускает консоль. | Текст логов, ASCII-арт, скорость задержек (`Sleep-Ms`). |
| **`Theme.psd1`** | Манифест модуля PowerShell (описание модуля). | Автора, версию, описание. |
| **`Theme.psm1`** | Мозг темы. Рисует баннер (рамку с информацией) и промт (приглашение ввода). | Цвета рамок, логику подсчета длины строк (для кириллицы), функции. |
| **`theme.json`** | Конфигурация баннера и промта. | Заголовок баннера (`title`), поля (`fields`), ширину рамки (`width`). |
| **`background/`** | Папка с фоновыми изображениями для тем. | Вы можете заменить картинки на свои (сохранив имена файлов), чтобы изменить фон. |

## 🎨 Как настроить свою тему (Custom)

Если при установке вы выбрали пункт `4`, скрипт создаст персональный профиль. 

- **Цвета**: Вводите их в HEX-формате (например, `#1A1B26` для фона и `#C0CAF5` для текста). Подобрать красивые сочетания можно на сайте [coolors.co](https://coolors.co/).
- **Шаблон промта**: В `theme.json` (или в `Theme.psm1`) можно использовать переменные:
  - `{time}` — Текущее время (ЧЧ:ММ:СС)
  - `{folder}` — Имя текущей папки (например, `Termulin`)
  - `{pwsh}` — Версия PowerShell (например, `v7`)
  - `{date}` — Текущая дата
  - `{username}` — Имя пользователя
  - `{hostname}` — Имя компьютера

Пример красивого промта:
```json
"prompt": "╭─[{time}]─[{folder}]─[{pwsh}]\n╰─❯ "
```

## ❓ Частые проблемы и их решение

**1. При запуске `Setup.bat` выдает кракозябры (непонятные символы)**
- **Решение:** Убедитесь, что вы запускаете файл из проводника (двойным кликом). Скрипт содержит `chcp 65001`, который включает UTF-8. Если вы запускаете из старого терминала, он может игнорировать кодировку.

**2. Ошибка `0x80070057` при открытии терминала**
- **Причина:** Отсутствует какой-то из файлов (например, фоновое изображение) или путь к pwsh.exe (Командной строке Power Shell 7) построен неправильно или файл отсутствует вовсе.
- **Решение:** Откройте папку, куда были распакованы все файлы. Проверьте целостность структуры и обязательно проверьте корректность пути к pwsh.exe (Обычно, он устанавливается по пути: C:\Program Files\WindowsApps\Microsoft.PowerShell_7.6.9.0_x64_ ...).

**3. Рамки баннера «разъезжаются» (правая граница съезжает)**
- **Причина:** Windows Terminal по-разному считает ширину кириллических символов и эмодзи.
- **Решение:** Мы добавили компенсирующий пробел в конце строк. Если рамка всё равно съезжает, вы можете уменьшить ширину рамки в `theme.json` (`"width": 60`).

**4. Скрипт не находит PowerShell 7**
- **Решение:** Скачайте и установите PowerShell 7 вручную с [официального сайта](https://aka.ms/powershell). После установки запустите `Setup.bat` еще раз.

**5. Как вернуть старую консоль?**
- **Решение:** Запустите `Setup.bat -Uninstall`. Если вы также хотите отключить тему в профиле PowerShell, откройте `$PROFILE` и удалите блок `# >>> TRL-Theme >>> ... # <<< TRL-Theme <<<`.
