# Мои инструменты 🛠️

Добро пожаловать! Этот репозиторий — коллекция различных утилит, скриптов и консольных приложений, которые я создал, изучая новое и исследуя различные темы в сфере IT. Каждый проект ориентирован на удобство пользователя и готов к установке и использованию на вашем ПК.

## 📦 Проекты

| Проект | Описание | Язык / Технологии |
| :--- | :--- | :--- |
| **[Termulin](https://github.com/forXsis/my_tools/tree/Termulin)** | Эстетичная и быстрая тема для Windows PowerShell с 3 предустановленными стилями и анимацией загрузки. | PowerShell, BAT |

## 🚀 Как использовать
Каждый проект находится в своей собственной директории и включает отдельный файл `README.md` с подробными инструкциями по установке и использованию. Перейдите в папку проекта, чтобы узнать больше.
